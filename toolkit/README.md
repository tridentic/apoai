# APOAI Toolkit

Contest-first reference for fast problem selection, preprocessing, model choice, training, and library quirks.

## Start here
- `decision-trees/README.md` for fast "what should I do now?" routing
- `contest-patterns/README.md` for recurring IOAI/APOAI-style tasks
- `libraries/sklearn/README.md` for the strongest classical ML baseline path
- `libraries/pytorch/README.md` for deep learning workflows
- `libraries/scipy/README.md` for optimization and math-heavy tasks
- `training/README.md` for loops, validation, and reproducibility
- `augmentations/README.md` for CV/NLP augmentation recipes
- `metrics/README.md` for objective/metric alignment
- `losses/README.md` for loss selection and combination recipes
- `competition-map/README.md` for practice-order planning

## Scope
- `domains/`: task-type playbooks for ML, CV, NLP, and genAI
- `libraries/`: practical API notes for NumPy, pandas, SciPy, PyTorch, and scikit-learn
- `decision-trees/`: problem-to-method selection
- `contest-patterns/`: historical task patterns and solution instincts
- `architectures/`: model-family cheat sheets
- `preprocessing/`: data cleaning and feature prep rules
- `augmentations/`: domain-specific augmentation recipes
- `metrics/`: evaluation and loss matching
- `losses/`: loss selection and composition
- `competition-map/`: competition difficulty and study order
- `training/`: loop, checkpoint, and experiment patterns
- `code-patterns/`: reusable notebook templates

## Use rule
Write the shortest reliable solution first. Upgrade only when the data or metric demands it.

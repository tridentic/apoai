## What to learn from each tier
- Beginner: pipeline discipline, EDA, validation, simple baselines
- Intermediate: transfer learning, metric tuning, augmentation, stronger CV
- Advanced: task-specific architectures, ensembling, calibration, advanced losses, and efficient experimentation

## Syllabus coverage map
- Vision: CNNs, ResNet, EfficientNet, DenseNet, ConvNeXt, attention modules, ViT, U-Net, DeepLabV3+, SegFormer, YOLO, Faster R-CNN, DETR, CLIP, diffusion
- NLP: RNN/LSTM/GRU, Seq2Seq, transformers, word embeddings, BERT-family models, NER, POS, sentiment, retrieval, RAG basics
- Core skills: preprocessing, error analysis, experiment tracking, GPU optimization, tuning, cross-validation, notebook hygiene, evaluation metrics
- Augmentation: flip, rotation, crop, resize, color jitter, noise, blur, CutMix, MixUp, Mosaic, random erasing, CLAHE, perspective, synonym/back-translation/text noise

## Order of attack
1. Learn the data shape and metric.
2. Build the simplest baseline.
3. Add preprocessing and augmentation safely.
4. Upgrade architecture only when baseline bottlenecks are clear.
5. Add ensembling/TTA/distillation last.
